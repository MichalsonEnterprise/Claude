# Preview deployment (Vercel)

- **URL:** https://global-pool.vercel.app (public, `X-Robots-Tag: noindex`). Vercel project `global-pool` in the owner's Hobby team, linked to `MichalsonEnterprise/Claude`, root directory `global-pool/apps/web`.
- **Continuous:** every push to `claude/keen-wozniak-q8eb3p` (the project's production branch) builds and replaces the production URL. Pushes that don't touch `apps/web`, `packages/`, `pnpm-lock.yaml` or `package.json` are skipped (`ignoreCommand` in `apps/web/vercel.json`). Per-commit deployment URLs (`global-pool-<hash>-…vercel.app`) are behind Vercel Authentication (owner login).
- **Build:** `apps/web/vercel.json` — pnpm 10.28.0 via `npx` (Vercel only reads `packageManager` from the repo-root package.json, which belongs to the unrelated landing page), git SSH → HTTPS rewrite for the public `@zksync/contracts` git dependency of `@chainlink/contracts`, packages built before `next build`. `next.config.ts` traces output files from the git repo root when `VERCEL` is set.
- **Mode (until 28 Nov 14:50 UTC):** web only, `NEXT_PUBLIC_DATA_SOURCE=mock`, DEMO mode, no API. Works: public pages, homepage, Global Pool hub, games lobby + game screens (guest view), provably-fair explainer, legal/RG pages, design system, age gate. Does NOT work without a hosted API: sign-in (DEV MOCK exchanges a token with the API), member dashboard, wallet, entries, game play, admin console.
- **Not deployed:** NestJS API, Postgres, Redis, contracts. Hosting for these is an open owner decision (see PROJECT_STATUS.md §4).

## Hosted DEMO backend (Railway) — since 28 Nov 2026 14:50 UTC

- **API:** https://api-production-bf1f910a.up.railway.app (`/health`, Swagger at `/docs`). Railway project `global-pool` (owner's workspace): services `api` (Dockerfile.api), `Postgres`, `Redis` (private networking; no public DB endpoint).
- **Web wiring (Vercel env):** `NEXT_PUBLIC_DATA_SOURCE=api`, `NEXT_PUBLIC_API_URL`/`NEXT_PUBLIC_WS_URL` → the Railway API, `NEXT_PUBLIC_PRIVY_MOCK=true`. API `CORS_ORIGINS=https://global-pool.vercel.app`.
- **Mode:** `NODE_ENV=development` so the DEV MOCK player sign-in works (any e-mail + any 6-digit code; `nova.k@example.com` = the seeded DEMO player @nova.k). `DEMO_MODE=true`, `REAL_MONEY_ENABLED=false`, mock KYC/AML/randomness, country forced to PT (`DEV_COUNTRY_OVERRIDE`), jobs + Orbit Rush loop on, DEMO rounds auto-settle. **Anyone with the URL can sign in as any test e-mail** — never enter real personal data.
- **Secrets:** fresh random values stored only as Railway variables (JWT/admin JWT, TOTP encryption key, entry-salt key, mock signing secret, admin seed password, `ADMIN_SEED_TOTP_MASTER`). Never in the repo. DEMO admin credentials were handed to the owner in the session; admin TOTP secrets are derived from `ADMIN_SEED_TOTP_MASTER` (see `seedTotpSecret` in `apps/api/prisma/seed.ts`).
- **Seeding:** `SEED_ON_START=true` runs the DEMO seed (+ history and admin-ops fixtures) before the API starts on an empty database; it is now `false`. To reset: recreate the Postgres service, set `SEED_ON_START=true`, redeploy, set it back.
- **Deploying API changes:** from `global-pool/`: `RAILWAY_API_TOKEN=… railway up --service api --detach` (the token is injected by the session proxy). Not yet linked to GitHub auto-deploys — web deploys automatically on push, the API is redeployed on demand.
