# Accounting AI — Competitors

> Seed file. The agent must never publish an unsourced competitor claim
> (see `forbidden-claims.md`). Default posture: don't name competitors by
> name in generated content unless you add an explicit, sourced comparison
> here first.

## Landscape (general categories, not claims)

- Traditional Polish accounting software (desktop/cloud ERP-style systems).
- Cloud bookkeeping SaaS aimed at small businesses.
- Accounting offices' internal tooling / spreadsheets (the real default
  "competitor" for most SMBs).

## Default rule for the Content Strategist

Prefer contrasting with **the status quo process** ("ręczne porównywanie
faktur w Excelu") rather than naming a specific competitor product. This is
both safer and more persuasive for this audience.
