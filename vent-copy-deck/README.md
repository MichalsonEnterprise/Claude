**Status:** Ready for design implementation. Legal placeholders marked `[LEGAL REVIEW REQUIRED]`. Missing facts marked `[PLACEHOLDER]` — never invented.

---

## How to use this deck

1. Every page file follows the same structure: SEO block at the top, then numbered sections with `Eyebrow / Headline / Subheadline / Body / Cards / CTAs / Microcopy`.
2. Copy is written to be pasted directly into components. Line breaks inside body copy indicate intended paragraph breaks.
3. `[PLACEHOLDER: …]` marks a fact that does not exist yet (a date, a number, a name). Replace it before publishing that section, or ship the described pre-launch state.
4. `[LEGAL REVIEW REQUIRED]` marks compliance-sensitive wording. Nothing so marked should go live without counsel sign-off (MiCA in particular).
5. Terminology is binding. If a word is on the banned list in `brand/voice-and-terminology.md`, it does not appear on the site — in any language.

## Non-negotiable content rules (summary)

1. VENT is a **utility token**. It never represents equity, fund participation, dividends, profit rights, or claims on VENT Ventures I.
2. **VENT Sale proceeds → ecosystem development. VENT Ventures I capital → separate, future, separately raised.** These are never mixed.
3. Community output is **advisory**. Investment decisions of any future vehicle belong to a professional Investment Committee.
4. No promises of profit, price appreciation, yield, or guaranteed access to future financial products.
5. The mechanism is **VENT Lock**, and its rewards are **ecosystem rewards** — never "staking yield", "APY", or "passive income" in headline copy.
6. No invented partners, clients, investments, licenses, statistics, or history. Missing data is a labelled placeholder or a designed pre-launch state.
