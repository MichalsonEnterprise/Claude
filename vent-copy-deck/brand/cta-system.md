# VENT — CTA System

A single, consistent call-to-action vocabulary for the entire site. "Learn More" is banned; every CTA names the destination or the action.

---

## 3. Rules

1. One Tier-1 CTA per section. Never two filled buttons side by side.
2. CTA labels are 2–5 words, verb-first, and truthful — a button never oversells its destination ("Join the Institutional Waitlist" opens a waitlist form, nothing more).
3. Sale CTAs never use urgency ("now", "before", "last"). "Participate in the Distribution" is the strongest permitted form.
4. Pre-launch, any CTA whose destination doesn't exist yet becomes its waitlist form: "Get Notified at Launch".
5. Disabled states explain themselves: "Requires RESEARCH membership →" instead of a dead button.

## 4. Button microcopy states

| State | Pattern | Example |
|---|---|---|
| Default | Verb + object | Lock VENT |
| Loading | Present progressive | Locking… |
| Success | Past participle + next step | Locked. View your position → |
| Gated | Requirement + arrow | Requires KYC verification → |
| Pre-launch | Availability + notify | Opens in [PLACEHOLDER: phase]. Get notified → |
